## Overview
This lab exercise demonstrates creating a valid JSON dataset, asynchronously fetching and rendering JSON data onto a webpage using modern native JavaScript (`fetch()`), and implementing equivalent DOM manipulation and click event handling using jQuery 4.0.0.

## Files Included
* `books.json` – Valid JSON dataset containing an array of book objects (`title`, `author`, `publicationYear`, and `genres`).
* `books.html` – Web page that retrieves `books.json` via `fetch()` and safely renders specific book details and error handling to the DOM.
* `jquery-dom.html` – Web page demonstrating DOM text updates, CSS class additions, and click event handling using jQuery 4.0.0.

## How to Run
1. Download or clone this folder to your computer.
2. Open the folder in VS Code and launch `books.html` using the **Live Server** extension *(Note: Opening `books.html` directly by double-clicking may block `books.json` from loading due to browser CORS policies).*
3. Open `jquery-dom.html` in your browser (or via Live Server) to view the jQuery DOM updates and test the button click alert.
